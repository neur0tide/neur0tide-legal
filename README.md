# neur0tide — legal & support pages

Public static site for App Store Connect URLs. The app source lives in a
separate private repository.

## Pages

| Page | App Store use |
|------|----------------|
| [privacy.html](privacy.html) | Privacy Policy URL |
| [support.html](support.html) | Support URL |

After GitHub Pages is enabled, URLs will be:

- `https://leafyus.github.io/neur0tide-legal/privacy.html`
- `https://leafyus.github.io/neur0tide-legal/support.html`

(Replace `leafyus` / repo name if you rename this repository.)

## Enable GitHub Pages

1. Push this repo to GitHub (public).
2. **Settings → Pages**
3. Source: **Deploy from a branch**
4. Branch: `main` / **/ (root)**
5. Save — the site is live in a few minutes.

## Update contact email

Edit `support@strachotta.com` in `privacy.html` and `support.html` if needed.
